# Security

Code Skater is a static browser game: it has no server, no accounts and no network calls, and it
stores only local settings and career progress in your browser.

## Reporting a problem

Please do not open a public issue for a security problem. Report it privately instead:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability** and describe the problem and how to reproduce it.

The maintainer will reply there. Fixes are released on the `main` branch and the live game.
